┌──────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START (3 Commands)                                         │
└──────────────────────────────────────────────────────────────────────┘

1. Setup (one-time):
   cd backend
   pip install -r requirements.txt
   brew install ffmpeg

2. Create .env file with your API keys:
   cp .env.example .env
   # Edit .env and add your actual API keys

3. Generate video:
   cd slides
   python3 pipeline.py
