TROUBLESHOOTING:
---------------

Issue: "FFmpeg not found"
→ Solution: brew install ffmpeg

Issue: "ELEVENLABS_API_KEY not set"
→ Solution: export ELEVENLABS_API_KEY='your-key'

Issue: "Import error: elevenlabs"
→ Solution: pip install elevenlabs

Issue: Font errors in slides_renderer.py
→ Solution: Check available fonts with: fc-list (Linux) or Font Book (macOS)
→ Use system fonts like "Helvetica" or "Arial"

Issue: Audio/video length mismatch
→ Solution: Already handled! FFmpeg -shortest flag auto-syncs

Issue: Voice doesn't sound right
→ Solution: Run get_available_voices() to test other options
