┌──────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START (3 Steps)                                            │
└──────────────────────────────────────────────────────────────────────┘

1. Setup Environment (one-time):
   cd backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   brew install ffmpeg

2. Configure API Keys:
   cp .env.example .env
   # Edit .env and add:
   # ELEVENLABS_API_KEY=your-key-here
   # GEMINI_API_KEY=your-key-here

3. Generate Video:
   cd slides
   python3 pipeline.py

   Output: final_output/confucius_lecture_summary.mp4
