🚀 QUICK SETUP GUIDE - Using .env File
=====================================

STEP 1: Install Dependencies
-----------------------------
cd backend
pip install -r requirements.txt
brew install ffmpeg  # macOS


STEP 2: Create .env File (EASY WAY!)
-------------------------------------
cd backend
cp .env.example .env

Now edit the .env file and add your API keys:
  ELEVENLABS_API_KEY=your-actual-elevenlabs-key-here
  GEMINI_API_KEY=your-actual-gemini-key-here

Get your API keys:
• ElevenLabs: https://elevenlabs.io/
• Gemini: https://makersuite.google.com/app/apikey


STEP 3: Run the Pipeline
-------------------------
cd slides
python3 pipeline.py

That's it! The .env file will be automatically loaded.


ALTERNATIVE: Environment Variables
-----------------------------------
If you prefer, you can still use environment variables:

export ELEVENLABS_API_KEY='your-key'
export GEMINI_API_KEY='your-key'


WHY .env FILE IS BETTER:
------------------------
✅ No need to export variables every time
✅ Keys persist across terminal sessions
✅ Easier to manage multiple projects
✅ Follows industry best practices
✅ Works automatically when you run scripts


FILE STRUCTURE:
--------------
backend/
├── .env                    ← Your actual API keys (NEVER commit this!)
├── .env.example           ← Template file (safe to commit)
└── slides/
    ├── env_loader.py      ← Auto-loads .env file
    └── pipeline.py        ← Just run this!


SECURITY NOTE:
--------------
The .env file is in .gitignore and will NOT be committed to git.
This keeps your API keys safe!
